One face, one size. Hierarchy is carried by weight, slant, case and colour, so every glyph sits in the same cell. Links look like this, inline code like render(), keys like Ctrl K, program output like exit 0 and variables like width.

Edits read as a diff: border-radius: 8px border-radius: 0. Search hits are marked, TUI is an abbreviation, and small print stays the same size, only quieter.

Panes and grid

<section>, <article> and <aside> are bordered panes. A heading as the first child becomes the pane title on the top border. data-grid subdivides any container; data-span lets a child cover several columns.
