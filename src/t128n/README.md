# t128n stylesheets

`tokens.css` and `layouts.css` are generated artifacts from the t128n design
system. They are vendored here unchanged so the app can load the same tokens
and layout skeletons as every other t128n surface.

Do not edit these files by hand. Regenerate them from the design system's
`DESIGN.md` and copy the resulting `dist/tokens.css` and `dist/layouts.css` into
this directory.
